# Fairy-tale track

1. Pick your story from the [Andersen collection](https://www.gutenberg.org/cache/epub/32572/pg32572-images.html).
2. Paste its text into `story.txt` so you have it to work with readily.
3. Re-mark `index.html` for your story with proper headings, paragraphs, and elements that fit the content.
4. Then bring your design to life. **Typography first, then layout, then the fancy stuff.** Get one section looking great before moving to the next.

## Structure

- `index.html`: example markup (replace with your story)
- `style.css`: plain starting styles (make them yours)
- `story.txt`: raw source text for reference
- `violin.jpg`: a sample illustration
- [`../css-properties.md`](../css-properties.md): CSS reference

# CSS Properties Reference

Essential CSS properties for creating beautiful typography and layouts:

## Typography & Text
- `font-family` - Choose fonts like serif, sans-serif, or specific font names - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/font-family)
- `font-size` - Control text size (px, em, rem, %) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/font-size)
- `font-weight` - Make text bold (normal, bold, 100-900) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/font-weight)
- `font-style` - Italic or normal text styling - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/font-style)
- `line-height` - Space between lines of text (improves readability) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/line-height)
- `letter-spacing` - Space between individual letters - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/letter-spacing)
- `text-align` - Align text left, center, right, or justify - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/text-align)
- `text-decoration` - Add underlines, strikethrough, or remove them - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/text-decoration)
- `text-transform` - Make text uppercase, lowercase, or capitalize - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/text-transform)
- `text-indent` - Indent the first line of paragraphs - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/text-indent)

## Color & Background
- `color` - Text color using names, hex (#ff0000), or rgb() - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/color)
- `background-color` - Background color of elements - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/background-color)
- `background-image` - Add background images or gradients - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/background-image)
- `background-size` - Control how background images are sized - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/background-size)
- `background-position` - Position background images - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/background-position)

## Layout & Spacing
- `margin` - Space outside elements (margin: 10px or margin: 10px 20px) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/margin)
- `padding` - Space inside elements, around content - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/padding)
- `border` - Add borders (border: 1px solid black) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/border)
- `border-radius` - Round the corners of elements - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/border-radius)
- `width` - Set element width (px, %, em, rem) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/width)
- `max-width` - Limit maximum width (great for readable text) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/max-width)
- `height` - Set element height - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/height)

## Float & Positioning
- `float` - Float elements left or right for text wrapping - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/float)
- `clear` - Clear floated elements (both, left, right) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/clear)
- `position` - Position elements (static, relative, absolute, fixed) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/position)
- `top`, `right`, `bottom`, `left` - Position coordinates for positioned elements - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/top)
- `display` - Control how elements display (block, inline, inline-block, none) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/display)
- `vertical-align` - Align inline elements vertically - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/vertical-align)

## Lists & Navigation
- `list-style-type` - Change bullet/number styles for lists - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/list-style-type)
- `list-style-position` - Position list markers inside or outside - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/list-style-position)
- `text-decoration` - Remove underlines from links - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/text-decoration)

## Effects & Interactions
- `opacity` - Make elements transparent (0 to 1) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/opacity)
- `box-shadow` - Add shadows to elements - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/box-shadow)
- `text-shadow` - Add shadows to text - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/text-shadow)
- `transform` - Rotate, scale, or move elements - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/transform)
- `transition` - Smooth animations between states - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/transition)
- `cursor` - Change mouse cursor (pointer, help, text) - [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/cursor)

## Common Patterns for Beginners
- Use `max-width: 600px` and `margin: 0 auto` to center content
- Set `line-height: 1.5` for better text readability
- Use `padding: 20px` to give content breathing room
- Try `float: left` or `float: right` on images for text wrapping
- Use `font-family: Georgia, serif` for traditional book-like text

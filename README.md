# WEB2026 Assignment 2 - Short Stories

## Overview
Learn HTML markup and CSS typography by taking a plain text story and designing it for the web.

## Getting Started

1. Clone or download this project
2. Install the Live Server extension in VS Code:
   - Open VS Code
   - Go to the Extensions view (Ctrl+Shift+X / Cmd+Shift+X)
   - Search for "Live Server" by Ritwick Dey
   - Click "Install"
3. Open the project folder in VS Code
4. Right-click on `index.html` and select "Open with Live Server"
5. Your default browser will open automatically with the project running

## Task

Your challenge is to take any story from the Hans Christen Andersen book on Project Gutenberg, and redo it for the web. Go through your story, try laying it out in Figma. Find some small illustrations from our hoard of public-domain image sources, and see what could go where. Maybe you'd like to add some fonts from Google Font.

For your reference, paste the story's text in `story.txt`. Look at the example in `index.html` to see how "The Travelling Musicians" has been marked up with:

- HTML structure (`<header>`, `<main>`, `<section>`, `<footer>`)
- Typography elements (`<h1>`, `<h2>`, `<p>`, `<em>`, `<strong>`)
- Lists and blockquotes for organizing content
- Classes for CSS styling "hooks"


## Files

- `story.txt` - The raw text of "The Bremen Town Musicians" fairy tale
- `index.html` - Example of how to mark up the story (study this!)
- `style.css` - Create your CSS styling here
- `css-properties.md` - [Reference guide for CSS properties](css-properties.md)
